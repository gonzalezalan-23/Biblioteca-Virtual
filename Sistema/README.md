# Biblioteca Virtual · EEST N°5

Sitio web de la biblioteca escolar de la EEST N°5, Ranelagh, Berazategui.

## Funcionalidades

- Catálogo público con búsqueda y filtros
- Portal de alumnos: préstamos, reservas y material de estudio
- Portal de docentes: solicitudes individuales y por lote para clase
- Panel administrativo: gestión de préstamos, usuarios, inventario, categorías, material y estadísticas

## Tecnologías

HTML, CSS y JavaScript · [Supabase](https://supabase.com) · [EmailJS](https://www.emailjs.com) · GitHub Pages

## Configuración

Requiere un proyecto Supabase configurado. Copiá `assets/js/config.js` y completá la URL y la clave `anon` de tu proyecto.

> La clave `anon` es pública por diseño. Nunca uses la `service_role` key en el frontend.
